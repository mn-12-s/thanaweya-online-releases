# تحديثات «نظام الدرجات أونلاين» — ثانوية منار المستقبل

مستودعٌ للمثبّتات وحدها: **لا مصدر البرنامج، ولا بيانات طلاب، ولا مفاتيح.**
يقرأ منه البرنامج إصداراته تلقائياً (electron-updater)، ولهذا هو عامّ.

- **للتثبيت أو التحديث يدوياً**: افتح [Releases](../../releases) وخذ أحدث `…setup-<الإصدار>.exe`.
- كل إصدارٍ فيه ثلاثة ملفّات: المثبِّت · `latest.yml` · `.blockmap` — **لا تُحذف أيٌّ منها**،
  فالمحدِّث يقرأ `latest.yml` ليعرف الإصدار، و`.blockmap` لينزّل ما تغيّر وحده.
- أول تثبيتٍ على كل حاسبة يدوي، وبعده تصل التحديثات وحدها بموافقة المستخدم.

🔴 هذه النسخة **مستقلّة**: لا تأخذ تحديثاتها من أي مستودعٍ آخر ولا تُعطيه — فترحيلات قاعدة
البيانات تختلف بين النسخ، وتحديثٌ من نسخةٍ أخرى يتخطّى ترحيلاً يظنّه منفَّذاً.
